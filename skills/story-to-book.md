# 技能：story-to-book（传记 PDF 成书 · 带原声二维码）

> 对应工作流步骤：auto-process.yml 步骤 3 ｜ 实现脚本：.github/scripts/story_to_book.py
> 调研来源：PDF 生成用 WeasyPrint（HTML/CSS 排版，开源）；二维码用 qrencode（开源命令行）；中文衬线字体用 Noto Serif CJK SC（思源宋体）。

## 功能
把整理好的故事排版成可打印、可手机扫码听原声的 PDF 传记。

## 输入
- 故事文件：`tests/stories/` 下全部 `*_故事.md`，按前缀分为两组各自成书：
  - 真人测试组：`真人测试_第X周_问题N_故事.md`（带「真人测试_」前缀）
  - 模拟测试组：`第X周_问题N_测试长者001_故事.md`
- 对应录音：`tests/fixtures/` 下与故事同前缀、同周次/问题号的音频文件

## 输出
- 路径：`tests/books/`
- 命名：
  - 模拟测试组：`测试长者001_第1辑.pdf`
  - 真人测试组：`真人测试_第1辑.pdf`（与模拟测试 PDF 互不覆盖；每 50 周故事合订为一辑）
- 中间产物：`tests/books/qr_codes/` 下每篇故事一张二维码 PNG（留档备查）

## 书籍排版要求
1. 封面：大标题「我的人生回忆录」，下方标注分组名称（真人测试组标「真人测试」，模拟组标「测试长者001」）与辑数（第 1 辑）；
2. 内页：每篇故事占 1 页，正文用宋体（Noto Serif CJK SC），段落小标题加粗；
3. 每页底部生成一个二维码，链接 = 对应原始录音文件的在线地址（GitHub Pages 上 tests/fixtures/ 下的音频）；
4. 二维码下方标注：「扫码收听原声」。

## 参数
- 页面：A4 ｜ 字体：Noto Serif CJK SC（无该字体时回退 Noto Sans CJK SC）
- 二维码：qrencode，边长 6，PNG；链接用 URL 编码，保证中文文件名可扫

## 幂等与重试
- PDF 每次由当前全部故事重新生成（覆盖旧版），故事无新增时不重复执行本步骤前的处理；
- 工作流内自动重试 2 次（共 3 次），仍失败则向访谈 Issue 评论错误原因。

## 验证方法
- PDF 可打开，封面 + N 篇故事页 = N+1 页；
- 手机扫描任一页二维码，应直接播放对应原始录音；
- 正文为宋体、标题加粗、每页底部有「扫码收听原声」。
