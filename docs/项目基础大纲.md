# 银发AI传记系统 · 项目基础大纲

> 版本：v0.1（内部测试）｜更新日期：2026-09-05
> 定位：以零代码/低代码方式，用 DeepSeek API + Codex + GitHub Skills/Agent 搭建银发 AI 传记系统（参考产品形态：Remindo）。

## 一、项目定位与目标

- 目标用户：银发长者及其家人
- 核心价值：低门槛（语音对话）讲述人生故事 → AI 自动整理成文 → 输出可保存、可分享、可打印的个人传记
- 当前阶段：内部测试（MVP），先跑通「访谈 → 整理 → 成书」闭环
- 建设原则：零代码/低代码优先；能调用 Skills/Agent 的环节不写代码；复杂代码留给后期

## 二、核心功能模块与关键步骤

### 模块 1：档案与用户管理
- 关键步骤：
  1. 建立长者档案模板（基本信息、家庭成员、人生阶段、照片资料清单）
  2. 设定家庭成员角色（主理人 / 协作者 / 审阅人）
  3. 制定访谈计划与进度看板
- 所需资源：`spreadsheets` / `spreadsheet-formula-helper`（档案表）、数据分析师 Agent

### 模块 2：智能访谈采集
- 关键步骤：
  1. 按人生阶段生成访谈提纲（童年 → 求学 → 工作 → 成家 → 晚年）
  2. 设计访谈引导语与追问策略（唤起回忆、情感安抚、方言与语速适配）
  3. 内测期以「文字问答 + 录音」模拟语音访谈，记录原始素材
  4. 每场访谈生成结构化纪要
- 所需资源：`content-research-writer`（问题设计）、`meeting-notes-and-actions`（访谈纪要）、内容创作师 Agent

### 模块 3：内容整理与记忆库
- 关键步骤：
  1. 录音转写与人工校对（内测用现成转写工具）
  2. 提取关键事件、人物、地点、时间，生成人生时间线
  3. 记忆打标签并入库（表格化管理）
  4. 交叉核对，处理记忆冲突与空白
- 所需资源：数据分析师 Agent、`spreadsheets`、`file-organizer`

### 模块 4：传记生成
- 关键步骤：
  1. 依据时间线与访谈素材自动生成章节大纲
  2. 分章撰写，提供文风选项（口述体 / 温情叙述体）
  3. 面向长者优化可读性（大字号、短段落、口语化）
  4. 润色、去 AI 味、家人校对
- 所需资源：内容创作师 Agent、`polish-prose`、`research-writing-skill`、`documents`

### 模块 5：多媒体与成品输出
- 关键步骤：
  1. 老照片整理、修复与增强
  2. 封面与章节插图生成
  3. 图文排版，输出 PDF 电子书与打印稿
  4. （可选）音频版回忆录片段
- 所需资源：`image-enhancer`、`imagegen`、`pdf`、`documents`、`presentations`

### 模块 6：家庭共享与回顾
- 关键步骤：
  1. 家庭圈分享与试读反馈收集（内测期先以文件 + 家庭群方式）
  2. 节日纪念册、周年回顾等衍生内容
  3. 根据反馈发起二次访谈与增补
- 所需资源：效率管家 Agent、`presentations`、`email-draft-polish`（邀请与通知文案）

### 模块 7：测试与质量保障
- 关键步骤：
  1. 编写内测用例（访谈流程、成书质量、数据安全）
  2. 用家人/志愿者完成 1–2 轮全流程试跑
  3. 成品验收清单逐项打分
  4. 问题记录、优先级排序、迭代排期
- 所需资源：代码工程师 Agent、`pr-review-ci-fix`、`create-plan`

## 三、所需 GitHub Skills / Agent 资源清单

### 已安装 Skills（本机可用）
- `deepseek-monitor`：API 余额与用量监控（每次大批量调用后检查）
- `content-research-writer`：访谈提纲与内容研究
- `image-enhancer`：老照片修复增强
- `imagegen`：封面与插图生成
- `spreadsheets` / `spreadsheet-formula-helper`：档案表与用例表
- `documents`：Word 成书排版
- `pdf`：PDF 电子书输出
- `presentations`：纪念册 PPT / 家庭分享
- `meeting-notes-and-actions`：访谈纪要
- `file-organizer`：素材文件整理
- `create-plan`：阶段计划
- `polish-prose`：传记文字润色、去 AI 味
- `skill-installer`：按需安装新技能

### Agent 角色分工
- 内容创作师：访谈提纲、传记撰写、润色
- 数据分析师：记忆库表格、时间线、素材统计
- 效率管家：访谈排期、进度记录、文件整理
- 代码工程师：仓库维护、内测脚本（仅在必需时写轻量脚本）

## 五、内部测试里程碑

| 里程碑 | 目标 | 完成标志 |
| --- | --- | --- |
| M1 基础搭建 | 仓库、目录、大纲、档案模板就绪 | 本大纲 + 档案模板上线 |
| M2 首轮访谈 | 完成 1 位真实长者全流程访谈 | 访谈纪要 + 时间线入库 |
| M3 首本成书 | 输出第一本传记 | PDF 电子书 + 打印稿交付 |
| M4 反馈迭代 | 家庭试读并迭代 1 轮 | 验收清单通过 + 问题清零 |

## 六、风险与注意事项

- 数据隐私：长者口述内容敏感，仓库保持不公开个人信息；进度文档仅存本地
- API 成本：DeepSeek 按量计费，大批量生成前先查余额（deepseek-monitor）
- 长者体验：大字号、慢语速、多鼓励；家人全程陪伴校对
