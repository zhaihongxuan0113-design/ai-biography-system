# 语气保留指南

> **目标**：从"录音"到"成书"全程，让长者的口音、口头禅、节奏和情感原汁原味地留在传记里——读者打开书，就像听见老人家本人在说话。
> **核心原则（贯穿三步）**：先留原话，再谈整理；AI 只做"誊写和排序"，不做"改写和代言"。

---

## 第一步：语音转文字时，保留口语化表达

**要点：要"逐字稿"，不要"润色稿"。**

1. **转写时保留原样**
   - 长者的方言词、"嗯、啊、那个、然后呢"等语气词、重复的话，全部照录，不删除、不合并。
   - 说不完整的半句话保留原样，整理阶段再处理，转写阶段一律不动。
2. **用标点记录节奏和情绪**
   - 停顿：用省略号"……"（停得越久省略号越多）；
   - 加重语气：用叹号"！"；
   - 笑声/叹气/哽咽：用方括号标注，例如 [笑]、[叹气]、[哽咽]、[沉默片刻]；
   - 声音突然变大变小：标注 [声音提高]、[压低声音]。
3. **推荐工具（GitHub 开源，低代码）**
   - 逐字转写（自动保留语气词）：[CrisperWhisper](https://github.com/nyrahealth/CrisperWhisper)（自带填充词检测，专门保留口语原貌）；
   - 标点分段与停顿标注参考：[Whisper 讨论帖：标点与停顿](https://github.com/openai/whisper/discussions/712)；
   - 中文口述史工具集合：[HistoryAIToolkit（口述史 AI 工具箱）](https://github.com/crisishistory/HistoryAIToolkit)；
   - 中文口述自传平台（可参考其"口述-成稿"流程）：[言心 AI 口述自传平台](https://github.com/franz1022/yanxin-ai-oral-autobiography-platform)。
4. **实操流程（零代码）**
   - 用手机/录音笔录下访谈，格式选 mp3/wav，环境安静、离长者近一点；
   - 把录音交给转写工具得到逐字稿；
   - **人工校对一遍**：转写错误（尤其人名、地名、方言）对照录音改正，情绪标注补齐。

## 第二步：AI 整理故事时，保留说话风格和情感

**要点：用"双层文本"工作法——逐字稿永远保留，成书稿才做整理。**

1. **双层文本法**
   - 第一层（原始层）：第一步产出的逐字稿，永远存档不动；
   - 第二层（成书层）：AI 只对逐字稿做"去重复、顺语序、分段落"，不改词、不改腔。
2. **给 AI 的整理规则（可直接抄进 DeepSeek 提示词）**
   - "保持第一人称，保留'我'的口吻";
   - "保留所有方言词和口头禅，可以在旁边用小括号注明意思，例如：'这闺女真俊（俊=漂亮）'";
   - "只删除重复和跑题的部分，不替换任何原词、不美化、不总结升华";
   - "保留 [笑]、[叹气] 等情绪标注，或在文中用'说到这里，老人家笑了'自然写出";
   - "改完请对照原稿检查：每句都能在原稿里找到出处。"
3. **人工把关**
   - AI 整理完一段，读给长者听，问："这是不是您说的意思？" 按长者意见改回。
   - 建议每章做一次"回读确认"，既保质量，也是很好的陪伴环节。
4. **可参考的 GitHub 资源**
   - 中文人生传记技能：[BigSeedSkill（人生传记 Skill）](https://github.com/kobenfang/BigSeedSkill)；
   - 自传生成流程：[Life Bookshelf AI（人生书架）](https://github.com/life-librarians/life-bookshelf-ai)。

## 第三步：生成书籍时，保留老人的原声（二维码链接）

**要点：书里每个章节放一个二维码，手机一扫就能听到长者亲口讲述。**

1. **准备原声文件**
   - 每章对应的访谈录音，剪成 1～5 分钟的小段，文件名统一：`第01章_童年.mp3`；
   - 格式统一 mp3（手机、微信都能直接播放）。
2. **把原声放进书里（零代码二维码）**
   - 用免费二维码工具（如"草料二维码"）把音频链接/音频文件生成二维码图片；
   - 排版规则：每章开头放一张二维码，下面印一行字："扫码听本章原声"；
   - 每个二维码只对应一段音频，避免一段太长。
3. **文件保存规范（家庭共享）**
   - 建一个"家庭记忆库"网盘文件夹（如百度网盘/阿里云盘/腾讯微云），分类：`录音原始稿 / 逐字稿 / 成书稿 / 原声二维码`；
   - 权限：家人群共享"可查看"，只由一位管理员"可编辑"，防止误删；
   - 命名规则：`类别_日期_内容_第几段`，例如 `录音原始稿_20260905_童年上学的路_01.mp3`。
4. **进阶（可选）**
   - 想让 AI 用长者的声音"朗读"全书，可参考声音克隆开源项目（涉及授权，需征得本人和家属同意）：[FamilyLegacy](https://huggingface.co/spaces/build-small-hackathon/FamilyLegacy)、[Voicebox](https://github.com/jamiepine/voicebox)、[VoiceCraft](https://github.com/gangtao/VoiceCraft)。

- [ ] 录音已转成逐字稿，语气词、停顿、情绪标注完整
- [ ] 逐字稿已人工校对并存档（原始层）
- [ ] AI 整理稿对照原稿检查过，没有改词、没有丢情绪
- [ ] 整理稿已读给长者听并得到确认
- [ ] 每章原声已生成二维码并排入书中
- [ ] 所有文件按命名规范存入家庭记忆库
