# 长者档案模板

> **这份档案是写传记的"底稿"**：把长者的人生先分成几个抽屉装好，后面访谈和整理故事时随时取用。
> **怎么用**：由家人或访谈助手陪长者一起填，可以聊天式填写，一次填不完就分几次。长者口述、助手记录，注意把长者原话记下来，不要"翻译"成书面语。
> **打印提示**：建议用 A4 纸打印，字号调大一号；横线上写字或空白处贴老照片都可以。

## 填写小贴士

1. **以聊天为主**：问题只是引子，长者说到哪儿就跟到哪儿，随时把新线索记进对应栏目。
2. **保留原话**：方言、口头禅、"我们那时候……"这样的说法都照原样记，这是传记里最宝贵的味道。
3. **照片是宝贝**：老照片背面用铅笔轻轻写上时间、地点、人物，扫描后另存一份电子档。
4. **定期补充**：每访谈完一周（2 个问题），把新想起的内容补进本模板对应位置。
