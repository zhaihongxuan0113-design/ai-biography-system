# 集中录音指南（给爸爸的录音说明 + 新录音笔录制规范）

---

## 第一部分：给爸爸的录音说明

> 传主：翟连柱（父亲）｜记录整理：翟红宣（儿子）｜翟红宣之母：马晓萍


爸，录这个不用紧张，就是咱爷俩聊天，我把想问的整理成了几大块：小时候、当兵、上班、做生意、家里的事。您就一条一条聊，我陪着您聊。几个小提醒：

- **就当唠嗑**：想到哪儿说到哪儿，跑题了没关系，跑出去的都是故事，我都能接着。
- **越小的事越好**：一条胡同、一个外号、一盘棋、一顿饭、一块两块钱的事，都讲。大道理不用讲，就讲当时是怎么回事。
- **说错了、说重复了都没事**：不用停、不用改口，接着往下说就行，后面我来整理。
- **人名、地名、年月日越具体越好**：想得起来就报名字，想不起来就说“好像姓什么”，也不碍事。
- **一条录音开头先说一句**：“今天讲军旅的事”，这样我后面整理方便。
- **讲累了随时停**：一天录一两条就行，不赶时间，分几次录完都没问题。

## 第二部分：新录音笔录制规范

针对上一批录音转写效果不理想的问题，这次按下面几条录：

**一、录音环境**
1. 选家里最安静的房间，关门关窗。
2. 关掉电视、收音机，手机调静音并放远一点（半米以外）。
3. 空调、风扇、抽油烟机如果声音大，先关掉再录。
4. 屋里其他人暂时别说话、别走动。

**二、录音笔摆放**
1. 录音笔平放在桌子上，不要拿在手里（手拿着会有摩擦声）。
2. 麦克风朝嘴的方向，距离嘴 20～30 厘米（大约一拃），别太近，近了有喷气声。
3. 录音笔下面垫一块软布或纸巾，防止桌面震动声。
4. 录音前先试录 30 秒，回放听一遍：能听清、没杂音，再正式开始。

**三、说话的语速和音量**
1. 按平时唠嗑的速度说，不用刻意慢，但别抢话。
2. 音量正常偏大一点，像跟耳朵背的人说话那样。
3. 想不起来的时候停几秒没关系，别“呃”着赶，慢慢想、慢慢说。
4. 笑就笑、叹气就叹气，都录进去，这是好东西，不用憋着。

**四、单条时长与分段**
1. 一条录音 15～30 分钟最合适，最长别超过 40 分钟。
2. 一个话题录一条，比如“军旅·选拔当兵”录一条，“军旅·复员离开”再录一条。
3. 一天录 2～4 条，3～5 天录完全部，别一次录三四个小时。
4. 每条录完说一句“这段就到这儿”，然后按停止键。

**五、文件命名规则**
1. 每条录音文件名统一写成：`日期_阶段_序号`，例如：`20260922_军旅_01.wav`、`20260923_军旅_02.wav`。
2. 阶段名称用简写：童年 / 红卫兵 / 军旅 / 转业 / 国企 / 创业 / 家庭。
3. 录完把录音笔插到电脑上，把文件拷到「老爸录音」文件夹里即可，我来批量转写。
4. 如果录音笔自动命名（如 REC0035），没关系，拷进文件夹后我来统一改。

---## 第三部分：长期录音计划（总计 100 小时以上，约 12～14 个月）

这次不赶进度，目标是把你爸一辈子的话都聊出来。按下面顺序录，录到哪儿算哪儿：

| 次序 | 内容 | 预计时长 | 预计录音次数（每次45～60分钟） |
| --- | --- | --- | --- |
| 第1轮 | 第一部分 七大阶段深访（童年→家庭感悟） | 约 71 小时 | 约 80～95 次 |
| 第2轮 | 第二部分 人物志（36 位人物，每人一问到底） | 约 27 小时 | 约 30～35 次 |
| 第3轮 | 第三部分 年代回顾（1953–2026 逐年） | 约 20 小时 | 约 24～28 次 |
| 第4轮 | 第四部分 横切专题（钱、识人、健康、婚姻、子女等 10 个） | 约 9 小时 | 约 10～12 次 |
| 全程 | 第五部分 深挖工具包（10 个工具，对任何话题随时套用） | 不另占时间 | 随聊随用 |

**录音节奏**
1. 每周录 2～3 次，每次 45～60 分钟；老人状态好就多聊，累了就停。
2. 一个阶段录完再进下一个，不跳着来；工具包里的追问随话题顺手用。
3. 军旅（阶段三）、下海创业（阶段六）是最重的两块，时间只多不少。
4. 每条录音的命名规则不变：`日期_阶段_序号.wav`，例如 `20260922_军旅_01.wav`。
5. 每次录完拷进「老爸录音」文件夹，我来批量转写、整理成故事，边录边出稿。
6. 转写整理按《语气保留指南》执行：保留口头禅、停顿、笑声，不改写措辞。
