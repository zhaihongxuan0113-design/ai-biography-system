## 六、本轮排障记录（v3.x 迭代）

1. 初版（token_lcs 无上下文分段）会丢句：第 2 分段几乎为空 → 恢复 continuation；
2. 关闭幻觉修复后 FFFD 依然存在 → 确认乱码根因是字节级 token 不完整（与修复开关无关）；
3. 恢复默认修复后触发 `decoder_input_ids 269 + max_new_tokens 256 > 448`（v3 重写时遗漏上下文截断补丁）→ 补回 `MAX_CONTEXT_CHARS=60` 补丁；
4. 语气词连续重复（「啊， 啊， 啊，」）未合并 → 去重正则改为循环消费式；
5. 重叠分段逐词对齐偶发时间回跳 → 行时间取段内最早 + 行级单调钳制；
6. 最终版 v3.4：正文无 U+FFFD（替换为「□」并计数）、时间戳单调、停顿/情绪标注齐全。
