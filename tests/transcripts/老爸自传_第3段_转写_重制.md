# 老爸自传 · 第3段 · 转写（重制版）

接着录音，录名。这个我是上的小学五年级的时候，开始我打鸣了，就乱套了。我们参加了小学红兵，叫首都红兵，我们那是全无敌战队。跟着这个红兵的头啊，后来是马尔庆局的局长的儿子，叫李东林吧，叫李东民，李文双的儿子。然后北京市长，从北京市委二楼，这个，这我拿命，就乱套。学校停课了，我呢，这个，跟他们一起玩了些日子，后来我又上回老家，待了一堆日子。

六九年，六八年，六八年时候，我上了中学。中学参加中军红卫兵，一零九中，一零九中。他说，这个，没有上课。我呢，他们都去上课去了，我呢，因为红卫兵，我就参加了这个接待全国红卫兵的任务，就是首都清查指挥部，我在重分部，当红卫兵接待，任务就是接待全国各地红卫兵。我们进入天堂，无量电办公。当时人家都上课了，我呢还在外面参加首都，就是清查指挥部，出门分部，然后就接待湖南湖北广东广西的来访，来访山高的人员，都在无人店，是比较多。一直到我要快当兵了，那时候是该返校了，我基本上初中没有上课，都在外边参加首都，首都民兵，首都这个清查指挥部来。

那时候，然后听说要当兵了，接兵来了，我们住校。哎，这么着的话呢，我去学校找当兵的。这是一段很长的故事。在兵的排长叫陈公尔，湖南的。那时候当兵，跟那个我们那民国强，什么西左林啊，我们那国民兵，我们都一块，拿张纸都，咬破手指头，拿扎针，针扎破手指，写的写书，誓死保卫祖国。要有当兵，给个，结兵了，结兵看，当兵，兵力那么大。好，你们什么等上，我说我会想想气，因为我从小就会想想气，我会媳妇。因为我们家出身不好，因为小爷主嘛，我爷那时候从内蒙岛羊毛，来赶站的嘛，我们家做服装，后来供五六年，供的荷杨，因为家里雇人了，就给那个小野猪，小野猪是蒜农，地府反而要的是富农呗。但是我隐瞒城市，我说我们家是城市平民。后来这个带兵的人就比较沉默了，对我也不错，说你看你有什么特长，我就会想起，他说你能吓得过我吗，我说能，我说你要我要跟你下赢了你你得给我带走。结果一下二比零，他说他觉得没很没面子，他说怎么着吧，我把你这事也请了我们那个带兵的连长。那连长呢，打个梗，他也是个红男的，后来是我们那个东队大队长，姓张我记得。他来了，他来后看看，下一步就跟让成文，他们俩下，我一看下了两门又二比两，他们又一门，我没应了，后来就，没法弄了。后来请示带兵团团长，那团长呢，是我们的西武大队长，后来师兄为我们机武副船长，后来当了我们师子副船长，叫余三娃，后来忘了，他不对了。请他说这个兵要带走，说怎么着，咱们有个军医，也是湖南的，说你能让他跟他谈下能想到过他，行。结果白军一家人在我们学校，学校我们传达室那，学生考白系，好多的文官，我又二比零战胜他，结果一看丑鸡肉，没辙了，当兵的给我带个。好，等会这么着，先住在这。谢谢大家。
