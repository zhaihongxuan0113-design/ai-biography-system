# 老爸自传 · 第1段 · 转写（重制版）

现在开始录音。先回忆我的童年时代，我是1953年出生，在北京。后来改了户口。我的家，老家是河北人。祖辈听说是从湖南上游那边过来到河北，来这些南丰村。我的爷爷奶奶、太爷都在这里生活。我老家靠在巨马河旁边。我小时候记得，每年我都回老家跟我爸爸，我爷爷背着我。我们家有三十多棵枣树，爷爷给我准备的枣。我十岁那年，我爷爷去世了。奶奶很早就去世了，我也没见过奶奶什么样。

我是在北京出生的，出生在北京铜桥东大地，就是离天坛东门很近，也就有二百米吧，到天坛的城墙。小时候在天坛里边去玩。家里一共十个人，有我爸爸妈妈，还有我姥姥。我们家一共七个孩子，五女二男，我和我弟弟。我上面三个姐姐，第一个姐姐，一个弟弟，两个妹妹。

童年时代呢，我们跟大胡同里头和一些孩子发小玩耍。那时候一起玩的玩具，现在叫抽汉奸，我们那叫抽嘎嘎。还有那个逮马上，逮这个木头，叫逮塔，逮皮材。然后呢，还有一些叫挤狗屎，就一个人在墙根，挤到墙根，往出挣脱。还有那个挑鼻筋啊，还有那个围车，那个猪老小鹰猪老小鸡，老鹰猪小鸡啊。哎呀，小时候活动比较多。

我是上学比较晚，因为我这生日比较小，十二月份。在北京西园子小学，就在天坛北门上，这天坛北门。学校二层小楼，能看见天坛二层楼上，特别近，天坛北门也就二百多米吧。据说我们学校盖的是人美大小堂，在盛景的料，盖的那个鞋子小鞋，说什么都有。我在盯着，班主任和王老师、华老师、何老师。这老师呢，王老师，几个老师都喜欢我，因为我是孩子，我也给他们找了不少的麻烦。尤其我这个小学，在家淘气，经常请家长，尤其是何老师。每回一请家长，一跟着大家回来，我父亲就揍我一顿。那时候家教管得比较严。这老师呢，他就爱找你家长，看着让你爸爸揍一顿他就够了。

上学时候呢，也没有什么多大的兴起。经常放学以后呢，就上天坛公园和发小一起啊，打土仗，拿土仗，分两拨人，拿土搁这种。要不就是上这个虎生河，我们离这个黄鱼虎生河那远点，当然稍微远点，也不得太远。但虎生河里的游泳啊，当时也不会怎么游，会狗跑。小时候我爸爸教的狗跑，我们家里都会。在金马河外面长发，然后呢，在河里呢，抓点小鱼，回来我姥姥给我捡着吃。啊，抓小鱼，我记得特别清楚。我从小跟我姥姥长大，我姥姥背着我，这个去看病。

过节呢，家里呢，也没有什么太大的规矩，因为我们家里呢，也不是大家庭，因为农村出来的，来自于农村中地的。过节时候呢，就上我三叔家，给我三叔拜年，就是一边给我三十百年，给我三十。我三十比较没有二百年，他有时候过年过去就回来。我们到他家呢，给他磕个头，给我三十，让他给两块钱。

我小时候经常闯祸，跟人打架。有一次跟一个小子打架，我用皮带摆设小子，给脑袋给打花了。我姥姥在那去看病，晚上呢，他妈就带着他来找我爸爸，我爸爸这会儿一顿愁作。

我小时候也得过病，我很小的时候，那我也不记事了，可能在五岁的时候吧，我姥姥陪我看病，得过大脑炎，过去叫脑筋，脑筋什么炎。哎呀，老晕一起晕，后来呢，就好了，也没留下什么后遗症。有的是得大脑炎，都有后遗症，我没有得，没有。

从我们兄弟姐妹之间呢，最难忘的一件事呢，是什么呢？我记忆犹新。就有一次，我放学回来，反而回来以后呢，我捡了一个口琴。我想的话呢，没有，还没教老师，因为放学回来，等第二天再教老师。我先晚上呢，等我爸回来了，我说给我爸爸，我捡你口心吧。我爸爸二话没说，我上去给我一大嘴巴子，我给我弄倒了，还没起来的时候，又给我一脚，我揣一溜滚，跟我说以后不准捡东西，什么都不能捡。这就是教育不能贪小便宜。实际上我是准备叫老师的口琴，第二天买口琴叫老师了。我姐姐参加公司头一天，开了工资，我大姐给我买了一个口琴。这是我记忆犹新的一个事情，真是很难忘。所以说我现在，我从来地上有东西，我连看都不敢。

小时候中间的事情比较多。我们住在东大地一家大杂院，一家当时一家的食户。男巫是资本家终身，我们家是小业主。我们家呢三间房，这个晚上呢，比较热闹，都活大命了。这个南方，这个奶奶走了，从我老家去了，听说死在火车上，人打死了。南方那换成我们那个杰弗仙大爷仙老头，他算贫农吧，他会讲聊斋、三国演义。我们一到晚上就组织全户对孩子来上院，听新老头来讲故事，讲聊斋，讲那个三家五义，讲这些故事，挺有意思的。当然了，平房呢，屋里没有暖气，都是烧煤球和风扇煤。我呢，我们要是买煤球，风扇煤比较方便，因为我们互动口就是个大煤库，都出互动就能买到煤。

后来，好，今天录到这里。
